# 前端功能测试清单

## 测试前置条件

1. 后端运行在 `http://127.0.0.1:8000`。
2. 前端运行在 `http://127.0.0.1:5173/ui/`，或使用后端托管的 `http://127.0.0.1:8000/ui`。
3. 对话功能需要在 `.env` 配置可用的模型 Key：

```env
ANTHROPIC_API_KEY=your-key
MODEL_ID=your-model
ANTHROPIC_BASE_URL=your-compatible-endpoint
```

4. Docker Sandbox 执行需要可用 Docker Engine：

```env
DOCKER_HOST=npipe:////./pipe/docker_engine
```

Linux 远程 Docker 可使用 `tcp://docker-host:2376`。未配置或不可用时，Sandbox 工具会明确失败，不会回退到宿主 Shell。

5. `API_AUTH_USER` 和 `API_AUTH_ROLES` 只影响记忆的全局管理、用户作用域和只读边界，不再切换细粒度工具权限。

## 推荐测试顺序

1. 全局导航和主题。
2. 配置模型 Key 后测试多会话聊天。
3. Task、Cron、Skills、Tools、MCP。
4. 测试只读巡检直接执行。
5. 通过 BASH 请求生成 Pending Action。
6. 测试批准、拒绝、执行失败和后台任务。
7. 检查 Audit 中的 Session、Run、工具和审批事件。
8. 配置 Docker 后测试 Sandbox 创建、隔离、超时和清理。
9. 重启后端，测试 Session 历史、Run 中断原因和安全点继续。
